<!-- This file explains how easy and Zone 2 running supports aerobic endurance. -->

Zone 2 is commonly used to describe a relatively easy aerobic effort, but heart-rate boundaries are not universal. Heart rate can be affected by heat, hills, fatigue, hydration, stress, and sensor accuracy.

A practical indicator of easy aerobic running is that the athlete can speak in comfortable sentences without struggling. Easy running develops the ability to spend more time moving while keeping fatigue manageable.

Zone 2 or conversational running is useful when the athlete needs to build endurance, increase weekly volume gradually, improve recovery between harder sessions, or avoid making every run moderately hard.

The goal is not to force one exact heart-rate number. The athlete's own pace, heart rate, breathing, and perceived effort should be considered together.
