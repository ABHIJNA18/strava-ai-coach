<!-- This file explains how tempo running can support sustained pace development. -->

Tempo running is a sustained effort that feels controlled but challenging. It is usually slower than an all-out effort and faster than ordinary easy running.

Tempo work can improve the ability to hold a stronger pace for longer periods. It may be useful for athletes preparing for a sustained-distance goal, such as a faster 10K.

Tempo running should not be prescribed automatically. If the athlete's recent volume is low, recovery is poor, or most runs already appear moderately hard, more easy running may be a better priority.

Tempo sessions can begin with short blocks separated by easy recovery and gradually become longer as the athlete adapts.
